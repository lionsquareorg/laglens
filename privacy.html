LagLens Privacy Policy

Effective Date: November 2026 • Free Open Utility

1. The Core Principle: Zero Tracking

LagLens is built as an honest, private, client-side network utility. We operate under three straightforward guarantees:

  • No accounts: You never need to sign up, log in, or provide an email, phone number, or name.
  • No ads: There are no advertising SDKs, ad networks, banners, or tracking pixels.
  • No analytics: We do not collect behavioral tracking, telemetry, session recordings, or device fingerprints.

2. Local-Only Storage (Your Data Stays On Your Phone)

All settings, threshold preferences, test history, outage logs, and comparison profiles are stored exclusively on your device inside your browser's local sandbox (localStorage). None of this data is ever transmitted to us or any central server.

You can clear all stored history at any time with a single tap in the app's Settings screen.

3. How Diagnostic Network Requests Work

When you start monitoring, LagLens sends lightweight HTTP GET requests with cache-busting tokens to the endpoints you select (Google Edge, Cloudflare Edge, or a Custom URL you configure). Like any standard web request on the internet:

  • The target destination server receives the incoming connection and inherently sees your device's public IP address to reply.
  • LagLens uses no-cors mode and empty response generation endpoints (such as Google's generate_204) to measure round-trip elapsed time.
  • No payload, cookies, or user information are intentionally transmitted with these diagnostic probes.

4. Permissions Used

  • Keep Screen Awake: Uses the standard Screen Wake Lock API to prevent the display from sleeping during an active latency test. It is requested on demand and released when monitoring stops.
  • Sound & Haptics: Uses the local Web Audio API and navigator.vibrate for notifications. No audio recordings or microphone access are requested.
  • Browser Notifications: Used to notify you about connection degradation when enabled.
